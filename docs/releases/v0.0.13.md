# suyu v0.0.13

Faster Vulkan pipeline setup, smaller game exports that run from your own game
file, a new optional portable export type, and clearer key and firmware setup.

## Faster Vulkan pipeline setup

On supported Vulkan drivers, suyu now reuses compiled graphics pipeline parts and links a
new pipeline quickly when it is first needed. This reduces long waits caused by graphics
pipeline creation. Suyu builds a fully optimized version in the background after the
first use.

The change is enabled only when the driver reports fast graphics pipeline library
support. Other devices keep the previous path automatically; this includes the tested
macOS MoltenVK build. Android also keeps the previous path by default. If a supported
driver has a rendering problem, turn off **Use graphics pipeline libraries** in the
Vulkan settings.

This improves pipeline waits; loading transitions can still pause for other reasons.

## Game exports run from your game file

Exports no longer copy the game's files. An export records the game file you
selected and opens it at every launch with the keys installed in suyu, the same
way suyu itself plays it. A JIT export is now tens of megabytes instead of the
size of the game. If the game file has moved, the export says so and names the
path it expected; export the game again from its new location.

Exports are built in a temporary folder, checked, and only then moved into place.
An existing export is never silently replaced.

## Portable exports (optional)

**Package type → Portable** copies your game file, its installed update and its
installed DLC into the export unchanged, sealed to the console your keys come
from. The export then runs without the original file. On first launch on a PC
without keys it asks for your key files and installs them for that user account,
as **Install Decryption Keys** does; later launches start directly. Keys from a
different console are refused. Keys and firmware are never copied into an export.

Portable needs an `sd_seed` entry in your keys. The export dialog shows whether
it is present, along with your keys, firmware, game file, update and DLC.

## Keys and installed content

- Launching a game without keys shows a prompt with **Install Decryption Keys…**
  instead of failing. An export started with keys that don't match the game says
  so and names the keys folder.
- suyu reads keys only from the key files you install, and keeps them in memory.
- Content installed from NSP files keeps its tickets, so DLC and updates installed
  that way keep working after suyu restarts.

## Downloads

Each release now includes a source archive of the bundled dependencies, and every
package carries `LICENSES/` and `THIRD-PARTY-NOTICES.txt`. Release packages are
checked automatically before upload.

**Re-export existing games** to get the smaller exports; older exports keep
working as they are.
